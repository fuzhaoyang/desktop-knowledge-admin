**Goal:** 应用启动先进入登录页（动态简洁背景 + 居中卡片），校验 `fuchaoyang` / `612731` 通过后进入主内容；主内容页标题栏右侧提供"退出登录"按钮，点击回到登录页；"记住我"勾选用 localStorage 持久化登录态。

### Task 1: 登录态模块 `src/auth.ts`

**Files:**
- Create: `src/auth.ts`

**Interfaces:**
- Consumes: 无（首个任务）
- Produces: `isLoggedIn: Ref<boolean>`、`login(username, password, remember): { ok: boolean; error?: string }`、`logout(): void`（后续 Task 2/3/4 依赖）

- [ ] **Step 1: 新建 `src/auth.ts`**

```ts
import { ref } from 'vue'

const AUTH_USER = 'fuchaoyang'
const AUTH_PASS = '612731'
const STORAGE_KEY = 'auth_logged_in'

export const isLoggedIn = ref(localStorage.getItem(STORAGE_KEY) === '1')

export function login(username: string, password: string, remember: boolean): { ok: boolean; error?: string } {
  if (username === AUTH_USER && password === AUTH_PASS) {
    isLoggedIn.value = true
    if (remember) localStorage.setItem(STORAGE_KEY, '1')
    else localStorage.removeItem(STORAGE_KEY)
    return { ok: true }
  }
  return { ok: false, error: '账号或密码错误' }
}

export function logout() {
  isLoggedIn.value = false
  localStorage.removeItem(STORAGE_KEY)
}
```
